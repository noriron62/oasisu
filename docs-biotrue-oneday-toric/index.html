バイオトゥルーワンデートーリック 乱視用とは

バイオトゥルーワンデートーリック 乱視用は、ボシュロムが展開する 1日使い捨てタイプの乱視矯正用コンタクトレンズです。近視用と 同じ独自素材「ハイパージェル」を採用し、レンズ含水率78%による うるおいをキープする設計を継承しています。

オブリークプリズムデザインによる回転安定性

レンズ下部を薄くしたプリズムバラストデザインをさらに最適化した 独自の「オブリークプリズムデザイン」により、4時〜8時方向の 斜めのバラスト部分でレンズの回転を抑え、安定した乱視矯正を 実現しているとされています(臨床試験では約97%が眼上での回転量 10度以内と評価されています)。

非球面デザインによる見え方

非球面レンズデザイン「HDオプティクス」により、球面収差を補正し、 夜間や薄暗い状況下でのにじみ・ぼやけを軽減するとされています。
