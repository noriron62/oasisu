メダリストワンデープラス乱視用とは

乱視用ならではの安定した見え方

乱視用レンズは、瞬きのたびにレンズの向きがズレると視界がぼやけやすく なります。レンズの形をしっかり保つ設計により、裏表も分かりやすく、 毎日のつけはずしがしやすいよう工夫されているとされています。

定番ブランドとして長く展開されている商品のため、他の乱視用1日使い捨て レンズと比べても、比較的購入しやすい価格帯で販売されている傾向があります。
