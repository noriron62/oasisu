運営者について

当サイト「コンタクトレンズ最安値通販価格情報」は、norironが個人で運営しています。

私自身も日常的にコンタクトレンズを使っていて、「毎回どのショップが一番安いのか調べるのが手間だな」という実感がありました。きっと、ほかのコンタクト愛用者の方も同じことを考えているんじゃないかなと考えて、価格を毎日チェックして一覧にできないかと考え、皆さんに愛用してもらおうと、このサイトを作りました。

サイトの目的

楽天市場・Yahoo!ショッピングで販売されている、人気の1日使い捨てコンタクトレンズの価格を毎日チェックし、購入単位(箱数・パック)ごとの最安値ショップをまとめています。

「同じ商品なのに、ショップによって単位や価格の見せ方がバラバラで比較しづらい」という状況を整理し、1枚あたりの単価で公平に比較できることを目指しています。

価格情報について

掲載している価格は、楽天市場・Yahoo!ショッピングの価格を、毎日チェックして更新しています。

※ 表示価格は取得した時点のものであり、実際の購入時点の価格・送料・在庫状況とは異なる場合があります。ご購入の際は、必ず各ショップの商品ページで最新の情報をご確認ください。当サイトの情報の正確性について、完全性を保証するものではありません。

広告について

当サイトは、楽天アフィリエイト・Yahoo!ショッピング等の広告プログラムを利用しています。

コンタクトレンズのご購入にあたって

コンタクトレンズは高度管理医療機器です。当サイトは価格比較を目的とした情報サイトであり、医療的なアドバイスを行うものではありません。ご自身の目に合った商品かどうかは個人差があるため、ご購入・ご使用にあたっては、眼科での検査・処方をふまえたうえでご検討ください。
